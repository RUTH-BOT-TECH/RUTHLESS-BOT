# Temporary WhatsApp profile clone

Only verified bot owners/sudo can use `.clone`, replying to an ordinary group message or mentioning a group member. The bot must have observed that participant's WhatsApp push name in a group message within the last seven days of the current process. A recently received message is most reliable; old replies may not have a usable name after restarts. WhatsApp privacy settings can prevent profile photo or About access. Both the bot's current and target profile pictures and the bot's current profile name must be available; otherwise no change is attempted. If both About values are available they are copied/restored; otherwise About is left alone. Profile names and pictures are visible account-wide, not just in the group; the phone number, identity, messages and chat history do not change. Only clone a person with their permission and disclose parody where appropriate.

The bot persists an original-name/photo backup and 24-hour deadline *before* changing the profile. A configured durable database or a working pairing-service settings backup is required; an ephemeral local-only file is not sufficient. `.restoreprofile` or `.unclone` requests early restore. The bot checks once a minute and on WhatsApp reconnection; if offline at expiry it restores after reconnecting. Updates are WhatsApp requests, not a guarantee of display, and a failure can leave the profile partly changed. The saved backup is retained and retries run while connected. Account-level edits are blocked while the clone is active. Manual edits outside this bot may be overwritten by restoration. Existing auto-bio updates are paused while cloned and resume after restoration.

The original profile picture is stored in bot settings while active, including the encrypted pairing-service settings backup if enabled. Full-sized source images are bounded and converted to JPEG. This is personal data: use the existing private backup, don't share it, and restore promptly. Profile name observation is bounded, in-memory metadata (no message content), and is lost on restart. Real WhatsApp behavior depends on the Baileys version, privacy settings, and connectivity; synthetic tests do not prove live behavior.
